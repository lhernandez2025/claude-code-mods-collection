# claude-code-mods-collection

A private reference collection of public Claude Code mods, with a security-oriented analysis.

- [ANALYSIS.md](ANALYSIS.md): what each mod can reach, which to install, which to avoid
- [SOURCES.md](SOURCES.md): upstream repo and pinned commit for every folder in `mods/`

Nothing here is installed or executed. All code is by its upstream authors under their own licences (MIT, one Apache-2.0); each folder keeps its original LICENSE.
